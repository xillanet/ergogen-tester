Ergogenで作ったキー配列をiPad mini/Airで実寸大で表示するためのWebアプリ。

1) iPadのSafariで以下のURLを開く
https://xillanet.github.io/ergogen-tester/

2) 共有メニューから「ホーム画面に追加」でWebアプリ化

3) Ergogenで作ったSVGファイルをiCloudなどでiPadから読めるようにする

4) Webアプリを開き、左上のSVG読み込みで作ったSVGを指定

5) 正しければ表示されるはず

キー割り当て切り替えでコンビネーションキーだけが色がついているようにすると、コンビネーション入力が成功したときに別の音が鳴る。
